# Бот студии «ГАРАЖ»

Telegram-бот принимает заявки на услуги студии и пересылает их в группу звукорежиссёров.
Все заявки сохраняются в базе, состояние диалога переживает перезапуск бота.

## Что умеет

- **Запись**: клиент выбирает количество часов, день в календаре и свободное время.
  Занятые часы, прошедшее время и выходные выбрать нельзя.
- **Сведение**: принимает трек файлом MP3 или WAV.
- **Аранжировка / трек «под ключ»**: клиент пишет жанр.
- На каждом шаге есть кнопки «⬅️ Назад» и «✖️ Отмена», а также команда `/cancel`.

Команды в группе звукорежиссёров:

- `/bookings` — ближайшие записи;
- `/cancel_booking 12` — отменить заявку №12 и освободить её время.

## Сайт

Вместе с ботом в том же сервисе работает сайт студии: одна страница с пиксельной комнатой.
Предметы в комнате работают как меню: экран открывает заявку, календарь на стене показывает цены,
микрофон, мониторы, клавиши, гитара и стеллаж рассказывают о технике, плакаты ведут к адресу и контактам.
Весь текст продублирован обычным HTML ниже сцены.

- Заявка с сайта сохраняется в ту же базу и приходит в ту же группу с пометкой «с сайта».
  Запись с сайта занимает время так же, как запись через бота.
- Цены, услуги и часы работы сайт берёт из [`settings.toml`](settings.toml).
- Тексты сайта (адрес, контакты, оборудование) лежат в [`content/site.toml`](content/site.toml).
  Пустые значения на сайте показываются как «уточнить».
- Адрес для проверки, что сервис жив (и для пинга, чтобы бесплатный Render не засыпал): `/healthz`.
- Защита от спама: скрытое поле-ловушка и не больше 5 заявок за 10 минут с одного адреса.

Файлы сайта: [`website.py`](website.py) (сервер и API), `web/templates/index.html`, `web/static/`.
Картинки сцены собраны заранее скриптом `node tools/build_scene.js` (нужен только чтобы перерисовать сцену).

Посмотреть сайт без бота и Telegram: `python website.py`, затем открыть http://localhost:8080.
Заявки при этом пишутся в локальную базу, а вместо группы печатаются в консоль.

## Настройки

Цены, список услуг, часы работы, выходные и максимальная длина записи лежат в
[`settings.toml`](settings.toml). После правки файла бот нужно перезапустить.

Переменные окружения:

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `GROUP_CHAT_ID` | id группы звукорежиссёров (обычно начинается с `-100`) |
| `DATABASE_URL` | строка подключения PostgreSQL. Без неё бот пишет в локальный файл `garage.db` (SQLite), на Render такой файл стирается при каждом деплое |
| `PORT` | порт сайта. Render задаёт его сам, локально по умолчанию 8080 |

### База на Neon

1. Создайте бесплатный проект на neon.tech.
2. Скопируйте Connection string (`postgresql://...?sslmode=require`).
3. Вставьте её в Render → сервис garage-bot → Environment → `DATABASE_URL`.

Таблицы бот создаёт сам при первом запуске.

## Локальный запуск

```bash
pip install -r requirements.txt
BOT_TOKEN=... GROUP_CHAT_ID=... python garage_bot.py
```

Тесты: `pip install pytest && python -m pytest tests`
