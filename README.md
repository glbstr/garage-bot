# Бот студии «ГАРАЖ»

Telegram-бот принимает заявки на услуги студии и пересылает их в группу звукорежиссёров.
Все заявки сохраняются в базе, состояние диалога переживает перезапуск бота.

## Что умеет

- **Запись**: клиент выбирает количество часов, день в календаре и свободное время.
  Занятые часы, прошедшее время и выходные выбрать нельзя.
- **Сведение**: принимает трек файлом MP3 или WAV.
- **Аранжировка / трек «под ключ»**: клиент пишет жанр.
- На каждом шаге есть кнопки «⬅️ Назад» и «✖️ Отмена», а также команда `/cancel`.

Команды в группе звукорежиссёров:

- `/bookings` — ближайшие записи;
- `/cancel_booking 12` — отменить заявку №12 и освободить её время.

## Настройки

Цены, список услуг, часы работы, выходные и максимальная длина записи лежат в
[`settings.toml`](settings.toml). После правки файла бот нужно перезапустить.

Переменные окружения:

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `GROUP_CHAT_ID` | id группы звукорежиссёров (обычно начинается с `-100`) |
| `DATABASE_URL` | строка подключения PostgreSQL. Без неё бот пишет в локальный файл `garage.db` (SQLite), на Render такой файл стирается при каждом деплое |

### База на Neon

1. Создайте бесплатный проект на neon.tech.
2. Скопируйте Connection string (`postgresql://...?sslmode=require`).
3. Вставьте её в Render → сервис garage-bot → Environment → `DATABASE_URL`.

Таблицы бот создаёт сам при первом запуске.

## Локальный запуск

```bash
pip install -r requirements.txt
BOT_TOKEN=... GROUP_CHAT_ID=... python garage_bot.py
```

Тесты: `pip install pytest && python -m pytest tests`
